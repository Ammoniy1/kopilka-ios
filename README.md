# 🐷 Копилка — приложение и виджет для iPhone

Копилки на разные цели с прозрачной свинкой, которая наполняется монетками.
Виджет на главном экране и экране блокировки, выбор копилки и оформления прямо в настройках виджета.

## Как это собирается

Mac не нужен: при каждом изменении в ветке `main` GitHub сам собирает приложение
на своём Mac-сервере (вкладка **Actions**) и выкладывает файл `Kopilka.ipa` в **Releases**.

## Установка на iPhone (бесплатно, через AltStore)

1. На компьютере с Windows установи **iTunes** и **iCloud** с сайта Apple (не из Microsoft Store) и **AltServer** с altstore.io.
2. Подключи iPhone кабелем, в трее нажми значок AltServer → **Install AltStore** → выбери iPhone, введи свой Apple ID.
3. На iPhone: **Настройки → Основные → VPN и управление устройством** → доверь своему Apple ID.
   Включи **Настройки → Конфиденциальность → Режим разработчика**.
4. Скачай `Kopilka.ipa` из Releases на iPhone, открой его через **AltStore → My Apps → +**.
5. Добавь виджет: зажми главный экран → **+** → «Копилка».

Подпись бесплатного Apple ID действует 7 дней. AltStore обновляет её сам,
когда iPhone и компьютер с AltServer в одной сети Wi‑Fi.

## Перенос копилок из Scriptable

В Scriptable открой «Копилку» → **📤 Скопировать все копилки**,
затем в приложении нажми **Перенести копилки из Scriptable**.

## Структура

- `App/` — приложение (SwiftUI)
- `Widget/` — виджет (WidgetKit, выбор копилки через App Intents)
- `Shared/` — модели, хранилище в общей App Group, цвета
- `Resources/Assets.xcassets` — картинки свинки (16 стадий) и иконка
- `project.yml` — описание проекта для XcodeGen
